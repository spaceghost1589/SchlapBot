sc2lib contains domain-specific, analytical, and algorithmic tools built specifically to solve problems within the game environment.

    What goes here: Game-specific systems like tactical combat simulations (sc2_search), pathfinding, map geometry analysis (map_data, map_info), and build-order or placement logic.

Characteristics:
- Deeply coupled to the game domain.
- Rely heavily on API data types (like units, players, and game states)
    to perform heavy lifting and computational strategy.
